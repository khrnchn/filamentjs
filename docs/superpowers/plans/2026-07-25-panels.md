# FilamentJS Panels Package Implementation Plan

**Goal:** Build `@filamentjs/panels`: the pure config layer that ties a Drizzle model together with its form and table into a `Resource`, and groups resources into a `Panel` with navigation. No React, no routing, no DB. Pure TypeScript, fully unit-testable. The app consumes this to generate routes and a shell.

**Architecture:** `defineResource` takes a resource definition (model, form builders, built table, labels, nav, roles) and normalizes it (defaults plural label, humanized labels, nav sort). `definePanel` takes a base path plus resources and builds a navigation model (resources grouped by nav group, sorted) and a slug lookup. Depends on `@filamentjs/core`, `@filamentjs/forms`, `@filamentjs/tables`.

**Tech Stack:** TypeScript strict, Vitest, tsup.

## Global Constraints

- pnpm v10. Node >= 20. TS strict, no `any` in public signatures.
- No em dashes in comments/docs/commits. Comments explain gotchas only.
- tsup ESM build, exports types. Tests colocated `*.test.ts`.
- Package name `@filamentjs/panels`. Consumes only public exports of core/forms/tables.
- The Drizzle model is opaque here: type it as a generic `Model` (default `unknown`). Do NOT import drizzle-orm.

### Task 2: defineResource

**Files:** Create `packages/panels/src/resource.ts`, `packages/panels/src/resource.test.ts`. Modify `index.ts`.

**Interfaces produced:**
- `defineResource<Model>(input: ResourceInput<Model>): Resource<Model>` — fills defaults: `pluralName` defaults to `name + 's'`; `nav` defaults to `{}`; `roles` defaults to `[]`. Passes model/form/table/slug through unchanged.

- [ ] Step 1: Write failing test:
```ts
import { describe, it, expect } from 'vitest';
import { buildTable, t } from '@filamentjs/tables';
import { f } from '@filamentjs/forms';
import { defineResource } from './resource.js';

const table = buildTable({ columns: [t.text('title')] });

describe('defineResource', () => {
  it('fills defaults', () => {
    const r = defineResource({ name: 'Post', slug: 'posts', model: {}, form: [f.text('title')], table });
    expect(r.pluralName).toBe('Posts');
    expect(r.nav).toEqual({});
    expect(r.roles).toEqual([]);
    expect(r.slug).toBe('posts');
  });
  it('keeps explicit pluralName, nav, roles', () => {
    const r = defineResource({
      name: 'Category', pluralName: 'Categories', slug: 'categories', model: {},
      form: [], table, nav: { group: 'Content', sort: 2 }, roles: ['admin'],
    });
    expect(r.pluralName).toBe('Categories');
    expect(r.nav.group).toBe('Content');
    expect(r.roles).toEqual(['admin']);
  });
});
```
Note: `pluralName` default is `name + 's'` but the first test expects `'Posts'` from `'Post'` (works). Do NOT try to be clever about English pluralization; simple `+ 's'` is the documented behavior, and non-trivial plurals are passed explicitly.

### Task 3: definePanel + navigation model

**Files:** Create `packages/panels/src/panel.ts`, `packages/panels/src/panel.test.ts`. Modify `index.ts`.

**Interfaces produced:**
- `definePanel(input: PanelInput): Panel` — `basePath` defaults to `/admin`, `brand` defaults to `'FilamentJS'`. Builds `nav`:
  - Each resource becomes a `NavItem`: `{ slug, label: pluralName, href: \`${basePath}/${slug}\`, icon: nav.icon, sort: nav.sort ?? 0 }`.
  - Group items by `resource.nav.group` (undefined group -> a `NavGroup` with `label: null`).
  - Group order: if `navGroups` is provided, use that order for named groups; the null group goes last. Within a group, sort items by `sort` then `label`.
  - `getResource(slug)` returns the matching resource or undefined.

- [ ] Step 1: Write failing test:
```ts
import { describe, it, expect } from 'vitest';
import { buildTable, t } from '@filamentjs/tables';
import { defineResource } from './resource.js';
import { definePanel } from './panel.js';

const table = buildTable({ columns: [t.text('x')] });
const mk = (name: string, slug: string, nav?: { group?: string; sort?: number }) =>
  defineResource({ name, slug, model: {}, form: [], table, nav });

describe('definePanel', () => {
  it('defaults basePath and brand', () => {
    const p = definePanel({ resources: [mk('Post', 'posts')] });
    expect(p.basePath).toBe('/admin');
    expect(p.brand).toBe('FilamentJS');
  });
  it('builds hrefs and groups by nav group in navGroups order', () => {
    const p = definePanel({
      navGroups: ['Content', 'Access'],
      resources: [
        mk('User', 'users', { group: 'Access', sort: 1 }),
        mk('Post', 'posts', { group: 'Content', sort: 1 }),
        mk('Tag', 'tags', { group: 'Content', sort: 2 }),
      ],
    });
    expect(p.nav.map((g) => g.label)).toEqual(['Content', 'Access']);
    expect(p.nav[0]!.items.map((i) => i.slug)).toEqual(['posts', 'tags']);
    expect(p.nav[0]!.items[0]!.href).toBe('/admin/posts');
  });
  it('puts ungrouped resources in a trailing null group', () => {
    const p = definePanel({ navGroups: ['Content'], resources: [mk('Post', 'posts', { group: 'Content' }), mk('Setting', 'settings')] });
    expect(p.nav[p.nav.length - 1]!.label).toBeNull();
    expect(p.nav[p.nav.length - 1]!.items[0]!.slug).toBe('settings');
  });
  it('looks up a resource by slug', () => {
    const p = definePanel({ resources: [mk('Post', 'posts')] });
    expect(p.getResource('posts')?.name).toBe('Post');
    expect(p.getResource('nope')).toBeUndefined();
  });
});
```
